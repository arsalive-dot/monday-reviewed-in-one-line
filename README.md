# Monday, Reviewed in One Line

A make.fun entry: the funniest one-line review of my Monday, under 200 characters.

> One star: the coffee was cold, the standup ran 40 minutes, and the Wi-Fi gave up before I did.

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt` deterministically.
